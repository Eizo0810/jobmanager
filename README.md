#Jobmanager
求人管理システム（Spring Boot + PostgreSQL）

## 概要

求人情報、企業情報、受講生情報を一元管理するWebアプリケーションです。

求職者支援訓練における就職支援業務を想定し、
求人票管理や企業管理の効率化を目的として開発しました。

## 使用技術

- Java 21
- Spring Boot 3
- PostgreSQL
- Spring Data JPA
- Thymeleaf
- Bootstrap
- Docker
- Git / GitHub

## 主な機能

- ログイン認証
- 求人情報管理
- 企業情報管理
- 受講生管理
- CSV出力
- 検索・絞り込み
